# 02: 單次 Focus Session 倒數

**What to build:** 使用者可以手動按「開始」啟動一次 Focus Session,畫面上看到即時倒數,時間到會自然結束並回到等待狀態。這張票只驗證「一個 Phase 從手動開始到自然結束」這條完整路徑,還沒有 Break、沒有 Cycle 推進。

**Blocked by:** 01

**Status:** done

- [x] `usePomodoroTimer` 新增 `start` 動作:只有在狀態為「等待手動開始」時才合法
- [x] 開始後狀態變成「進行中」,並可以算出剩餘時間(以絕對結束時間為準,不是單純遞減的倒數器)
- [x] 時間到(倒數為 0)後,Phase 自然結束,回到「等待手動開始」狀態
- [x] 首頁有「開始」按鈕跟即時倒數畫面,按下後能看到倒數,跑完後畫面恢復成可以再按開始
- [x] 有測試覆蓋:開始後状态/剩餘時間正確、自然結束後回到等待狀態
